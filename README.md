# WebDAV 存储

把 Tau 的笔记、对话和附件同步到支持 WebDAV 的网盘或 NAS 上，也可以在写笔记时把图片和附件自动上传到 WebDAV，用用户名和密码登录即可。换电脑或在电脑与手机之间切换时，都能拿到同一份资料库数据。

## 开始使用

1. 在插件中心安装「WebDAV 存储」，再到插件页的「已安装」里打开开关。
2. 打开插件详情的「设置」，按需要分别配置同步或上传的「服务地址」、「用户名」和「密码」（坚果云等服务请使用应用密码）；「目录」可留空。用于资源上传时，如需使用自定义域名，再填写「公开地址前缀」。
3. 保存并测试连接后，到「设置 → 同步」或「设置 → 资源存储」选用 WebDAV。保存配置不会自动切换当前服务。

## 常见问题

**同步时报错，但账号密码没问题？** 有些网盘的 WebDAV 功能不完整，不支持 Tau 同步需要的操作。为了不覆盖你的数据，同步会停下来；遇到这种情况建议换一个 WebDAV 服务。

**上传成功了，但图片链接打不开？** 用于资源上传的目录需要能公开访问，或者通过「公开地址前缀」指向可公开访问的地址。

**能和别的资料库共用同一个位置吗？** 不要。每个资料库请使用单独的存储位置（可以用「目录」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 支持电脑与手机；同步与资源上传的账号分开填写，互不影响。
- 换了服务器或目录后，请确认它和原来同步的是同一份数据，避免把空目录当成新数据同步。
