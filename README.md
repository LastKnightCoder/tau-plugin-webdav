# WebDAV 同步存储

支持桌面、Android 和 iOS，通过插件中心安装后，在客户端的同步或图片附件设置中配置。账号仅用于当前服务；同步与上传分别填写，修改一方不会影响另一方。

把 Tau 的笔记、对话、附件同步到支持 WebDAV 的网盘或 NAS 上，用用户名和密码登录即可。换电脑或多台设备之间，都能拿到同一份数据。

## 开始使用

1. 在插件中心安装「WebDAV 同步存储」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开「设置 → 同步」，选择 WebDAV，填写服务器地址、用户名和密码；路径前缀可以不填。
3. 保存后，就可以用检查、上传、下载和自动同步了，用法和其他同步方式一样。

## 常见问题

**同步时报错，但账号密码没问题？** 有些网盘的 WebDAV 功能不完整，不支持 Tau 同步需要的操作。为了不覆盖你的数据，同步会停下来；遇到这种情况建议换一个 WebDAV 服务。

**能和别的知识库共用同一个位置吗？** 不要。每个知识库请用单独的存储位置（可以用「路径前缀」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 换了服务器或目录后，请确认它和原来同步的是同一份数据，避免把空目录当成新数据同步。
