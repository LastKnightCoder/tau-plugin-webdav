# WebDAV 儲存

將 Tau 的筆記、對話與附件同步至支援 WebDAV 的雲端硬碟或 NAS，也可以在寫筆記時將圖片與附件自動上傳到 WebDAV，使用使用者名稱與密碼登入即可。更換電腦或在電腦與手機之間切換時，都能取得同一份資料庫資料。

## 開始使用

1. 在外掛中心安裝「WebDAV 儲存」，再到外掛頁的「已安裝」裡開啟開關。
2. 開啟外掛詳情的「設定」，依需要分別設定同步或上傳的「服務網址」、「使用者名稱」與「密碼」（堅果雲等服務請使用應用程式密碼）；「目錄」可留空。用於資源上傳時，如需使用自訂網域，再填寫「公開網址前綴」。
3. 儲存並測試連線後，前往「設定 → 同步」或「設定 → 資源儲存」選用 WebDAV。儲存設定不會自動切換目前使用的服務。

## 常見問題

**同步時發生錯誤，但帳號密碼沒有問題？** 部分雲端硬碟的 WebDAV 功能不完整，不支援 Tau 同步所需的操作。為避免覆蓋你的資料，同步會自動停止；遇到這種情況建議更換其他 WebDAV 服務。

**上傳成功了，但圖片連結打不開？** 用於資源上傳的目錄須能公開存取，或透過「公開網址前綴」指向可公開存取的網址。

**可以和其他資料庫共用同一個儲存位置嗎？** 不要。請為每個資料庫使用獨立的儲存位置（可透過「目錄」區分），否則資料會互相覆蓋。

**停用外掛會刪除資料嗎？** 不會。你的設定與已同步的資料都會保留，重新啟用就能繼續使用。正在同步期間無法停用或解除安裝外掛，請待同步完成後再操作。

## 小提醒

- 支援電腦與手機；同步與資源上傳的帳號分開填寫，互不影響。
- 更換伺服器或目錄後，請確認目標位置與原本同步的是同一份資料，避免將空目錄當作新資料同步。
